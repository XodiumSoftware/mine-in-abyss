# Server Rules

The server rules are enforced in-game via the Rules command.

|         Rule         | Meaning                                                |
| :------------------: | :----------------------------------------------------- |
|  **Be respectful**   | No harassment, hate speech, or toxicity                |
|   **No griefing**    | Protected by anti-griefing systems, but respect builds |
|   **No cheating**    | No hacked clients, x-ray, or exploits                  |
|     **No spam**      | Keep chat readable                                     |
| **Use common sense** | If it feels wrong, don't do it                         |
