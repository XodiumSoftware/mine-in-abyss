# Joining the Server

<p class="page-summary">The server address, the Minecraft version, and how to join the Made in Abyss recreation.</p>

## Server Information

| Property    | Value                                                       |
| ----------- | ----------------------------------------------------------- |
| Server IP   | <pre><code class="language-text">{{server_ip}}</code></pre> |
| Version     | Java Edition {{mc_version}}                                 |
| Client Mods | Optional — the server is fully playable without them        |

## How to Join

1. Launch Minecraft Java Edition {{mc_version}}
2. Go to **Multiplayer → Add Server**
3. Enter the server address
4. Join and accept the resource pack prompt

## First Steps

Once you're in, here are some things to check out:

- Read the [Server Rules](rules.md)
- Look at [The Abyss](../layers/index.md) to see what waits below, and what the Curse costs
