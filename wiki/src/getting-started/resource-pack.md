# Resource Pack

Mine in Abyss uses a custom resource pack for creature textures and UI elements.

## Automatic Installation

The resource pack is **automatically served** when you join the server. Simply accept the prompt
and it will be applied on every join.

> The pack is **required**. If you reject it, the join will fail — you cannot play without it.

## What's Included

- Custom textures for the creatures of the Abyss
- UI and text overrides
